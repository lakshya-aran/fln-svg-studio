    How to make a drawing

    1. Pick a template under Start from, or start blank. Set the file name, category, title and description.
    2. Draw with code. Return the drawing as a string of SVG shapes. Helpers like eye(), tubes(), bumpy() and digit() do the fiddly parts. The preview updates as you type.
    3. Fix the style check. Everything should be green: black and white, rounded lines, light ink, inside the safe area.
    4. Check the small preview. If a child would not name it at worksheet size, add a stronger clue (a stem, a cut half, a label) or change the angle.
    5. Save to review. In Review, mark each drawing Approve or Redo with a note, then Copy verdict to share it.
    6. Export approved. The ZIP has one folder per category (fruits/apple.svg), ready to drop into the library repo.

    Style rules

    • Outline only, white fill, black #1A1A1A lines. No colour or grey.
    • Line weights: 8 for the main outline, 5 for inner details, 3.5 for fine texture. Always rounded ends.
    • Solid black only where it helps recognition — pupils, nostrils, a panda's patches, a bee's stripes.
    • Recognisable without colour: use real-world clues — seeds, cut halves, textures, labels like GLUE.
    • Realistic proportions, like textbooks and picture cards. Friendly cartoon faces are fine.
    • Canvas 0 0 512 512, object fills 80–90%, about 24 px padding, <title> and <desc> required.
    • Not allowed: images, text elements, fonts, gradients, filters, scripts, brand names.
    • Names: lowercase-kebab-case, e.g. cricket-bat.svg.

    Without code

    You can also draw in Inkscape (free), save as Plain SVG, then use Mode → Raw SVG or Review → Import to run the same style check and review.
